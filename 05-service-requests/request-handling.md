# Service Request Handling

## Purpose
This procedure describes a consistent way to receive and fulfil standard service requests.

## Handling steps
1. Receive the request through the approved service channel.
2. Confirm the requester's identity where required.
3. Check the request details and select the correct request type.
4. Validate eligibility and approval requirements.
5. Assign the request to the responsible team.
6. Complete the approved fulfilment steps.
7. Update the requester when appropriate.
8. Record completion and close the request according to the workflow.

## Sample service requests
- Request access to an approved application.
- Request installation of approved software.
- Request a password reset through the authorised identity process.
- Request information about an IT service.

## Request vs. incident reminder
A user asking for standard access is generally a service request. A user unable to access a service because it unexpectedly stopped working may be reporting an incident.

## Documentation checklist
Record the request, requester, approvals, assigned team, actions, completion evidence, and final communication as appropriate.
