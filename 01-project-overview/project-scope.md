# Project Scope

## In scope
- Introductory ITIL practice documentation.
- Jira Service Management project exploration.
- Sample incident creation and ticket updates.
- Request-type and workflow exploration.
- Priority, Impact, and Urgency concepts.
- Service request examples.
- SLA and escalation process documentation.
- Sample registers, reporting notes, and validation checklist.

## Out of scope
- Connecting to a production company environment.
- Supporting real users or resolving real business incidents.
- Integrating with enterprise monitoring, identity, or asset systems.
- Implementing production-grade automation.
- Making real contractual SLA commitments.
- Claiming that every documented process is configured in Jira.

## Assumptions
- Jira Service Management access and available features depend on the project plan, permissions, and product configuration.
- Sample data is fictional and intended for practice.
- The Jira interface may differ by product version and project template.

## Deliverables
- Separate Markdown documentation files.
- CSV templates for incidents, service requests, and SLA tracking.
- Screenshots of actual completed Jira activities.
- A project README and validation record.
