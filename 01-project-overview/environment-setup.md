# Environment Setup

## Purpose
This document records the environment used to practise the ITSM project.

## Required access
- A Jira Service Management account with permission to access or create a service project.
- A GitHub account for repository hosting.
- A text editor such as Visual Studio Code for Markdown and CSV files.
- A browser with access to Jira and GitHub.

## Setup procedure
1. Sign in to Jira Service Management.
2. Open the relevant service project or create a learning project if permitted.
3. Confirm that you can access the project work area and create a sample request.
4. Record the project name and project key in your private project notes.
5. Create the repository structure shown in the root README.
6. Add the documentation files and CSV templates.
7. Capture screenshots only after completing the corresponding Jira activity.

## Environment record
| Item | Value |
|---|---|
| Platform | Jira Service Management |
| Project | IT Service Project (as used in the exercise) |
| Sample ticket key | IT-1 |
| Operating context | Independent learning simulation |
| Documentation format | Markdown and CSV |

## Important
The exact Jira menu names and available configuration options may vary. Do not assume that a setting is active merely because it is described in this repository. Record the actual configuration and evidence from your own Jira project.
