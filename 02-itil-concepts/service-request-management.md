# Service Request Management

## Definition
Service Request Management handles predefined, user-initiated requests for services, information, access, or standard changes that are agreed as part of normal service delivery.

## Incident vs. service request
| Incident | Service request |
|---|---|
| An unplanned interruption or reduction in service quality | A request for a standard service or information |
| Focuses on restoring service | Focuses on fulfilling the request |
| Example: VPN unexpectedly stops connecting | Example: Request access to an approved application |

## Common examples
- Password reset, where permitted by policy.
- Request access to an approved application.
- Request installation of approved software.
- Request information about an IT service.

## Typical handling steps
1. Receive and log the request.
2. Validate the request details and requester.
3. Check approval requirements.
4. Assign the request to the responsible team.
5. Fulfil the request according to procedure.
6. Notify the requester and record completion.

## Control note
Access, software, and security-related requests must follow the organisation's approval and identity-verification policies. The examples in this project are illustrative only.
