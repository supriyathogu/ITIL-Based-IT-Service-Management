# Dashboard Documentation

## Purpose
A service desk dashboard gives support teams a summary of current work and helps them identify tickets that need attention.

## Useful dashboard information
- Open incident count.
- Tickets grouped by priority.
- Tickets grouped by status.
- Unassigned tickets.
- Tickets assigned to the current user.
- Recently resolved tickets.
- SLA goals at risk or breached, where SLA tracking is configured.

## Suggested dashboard layout
| Gadget or view | Why it is useful |
|---|---|
| Filter Results | Displays tickets matching a saved filter |
| Pie Chart | Shows distribution by status or priority |
| Created vs. Resolved Chart | Helps review ticket trends over time |
| Assigned to Me | Helps an agent monitor their own workload |
| SLA information | Helps monitor response and resolution goals, if available |

The availability and names of gadgets vary by Jira product and permissions.

## Screenshot guidance
When a dashboard has actually been created or viewed, save a genuine screenshot as `screenshots/jira-project-dashboard.png`.

Suggested caption:

> **Jira Service Desk Dashboard** — This view demonstrates how a support team can monitor ticket status, priority, assignment, and resolution progress.

Do not use this caption to imply that every suggested metric is visible if the screenshot does not show it.
