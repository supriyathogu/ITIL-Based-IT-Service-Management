# ITIL-Based IT Service Management (ITSM) Project

**Hands-on IT service desk simulation using Jira Service Management**

## Project overview
This independent learning project explores how an IT service desk receives, classifies, assigns, investigates, tracks, and resolves incidents and service requests. It uses Jira Service Management to practise ticket handling and documents related ITIL concepts, workflows, service levels, escalation, and reporting.

The project is a simulation. Sample tickets and records are illustrative and do not represent real company incidents or service commitments.

## Objectives
- Understand core ITIL service management practices.
- Explore Jira Service Management project and request-type configuration.
- Create and manage sample incident tickets.
- Practise assignment, internal notes, and workflow transitions.
- Understand Impact, Urgency, and Priority.
- Document service request, SLA, escalation, and reporting processes.
- Maintain clear evidence of completed configuration and validation.

## Tools and technologies
- Jira Service Management
- ITIL practices and terminology
- GitHub
- Markdown (`.md`) for documentation
- CSV for sample registers and tracking records

## ITIL practices covered
Incident Management, Service Request Management, Problem Management, Change Enablement, and Service Level Management.

## Practical scenario
A sample incident, **Unable to connect to company VPN**, was created in Jira Service Management as an Incident with the request type **Report a System Problem**. The ticket was assigned to the project learner and moved from Open to Work in Progress with an internal investigation note.

The ticket key displayed by Jira was `IT-1`. This key is specific to the Jira project instance used during the exercise.
