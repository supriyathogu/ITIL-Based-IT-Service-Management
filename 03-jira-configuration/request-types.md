# Jira Request Types and Work Types

## Purpose
This document explains the distinction between the work type used to classify work and the request type presented to a requester in Jira Service Management.

## Terms
- **Work type / issue type:** Classifies the underlying work item, such as an Incident or Service Request.
- **Request type:** Describes the request option a portal user selects, using language appropriate to the service desk.

The exact labels and relationship depend on the Jira project configuration.

## Request used in the exercise
| Field | Value |
|---|---|

## Selection guidance
Choose an Incident when a service is unexpectedly interrupted or degraded. Choose a Service Request when a user asks for a standard service, access, or information. Select the request type that best describes the user's need.
